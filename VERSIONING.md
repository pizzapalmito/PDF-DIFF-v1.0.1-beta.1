# Versioning

The authoritative application version is `package.json` → `version`. Current value: **1.1.0-beta.1**. The root package records in `package-lock.json` are synchronized mirrors. The UI footer and Help tooltip derive from the manifest at build time. The historical 1.0.0 release identifier is preserved.

Versions follow the portfolio SemVer policy. App version labels do not certify electrical engineering or code compliance. Representative real-project drawing acceptance remains outstanding, as documented in README and PROJECT-MEMORY.

The 2026-10-29 Revision bench redesign advances the minor version as a beta candidate. The user selected its direction; representative real-project and broader user acceptance remain outstanding. The initial design-only studies did not change the app version. `design/` retains the development comparisons and their historical screenshots; those pages are not included in the production entry point. No release, publishing or deployment is authorized by this document.
